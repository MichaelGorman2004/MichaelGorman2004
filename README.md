## Building RealDev

**A platform for developers to practice real software work and show companies what they can build.**

I founded RealDev in September 2025 and launched it in April 2026. I build and operate the product across the application, code execution infrastructure, and hiring marketplace.

**As of October 2026:** 1,500+ users and 6 companies using our talent marketplace.

- **Development workspace:** browser-based code editor, Docker-backed terminals, and saved workspaces.
- **Practical challenges:** build features, run code, and check submissions against automated tests.
- **AI feedback:** code reviews, contextual hints, and Understanding Checks.
- **Hiring marketplace:** developer profiles that bring completed work and resumes together for hiring teams.

**Stack:** TypeScript, React, Next.js, Node.js, Express, PostgreSQL, Redis, Docker, and AWS.

### Engineering behind the product

Building RealDev has given me hands-on experience with the system design problems behind an interactive developer platform:

- **Isolated code execution:** designing environments for user code with resource limits and reliable cleanup.
- **Real-time systems:** coordinating editor state, terminal sessions, and long-running work across service boundaries.
- **Data durability:** keeping saved work consistent across storage and active sessions, with failure recovery in mind.
- **Asynchronous processing:** managing background jobs, execution state, retries, and useful feedback when work fails.
- **Security and privacy:** enforcing authentication, access controls, subscription entitlements, and consent around developer data.
- **Production operations:** working across deployment, monitoring, performance, and infrastructure costs.
